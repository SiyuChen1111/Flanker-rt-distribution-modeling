# Current Results and Limitations

## Human pattern

- RT distributions have a clear right tail.
- Mean RT is around 0.60s in the matched young group.
- Error RT is often faster than correct RT in the target condition.

## Current model pattern

- The DMC + variational evidence branch produces a right tail.
- Mean RT is around 0.45s in the current smoke summary.
- The model is still faster than human data overall.

## Fast-error effect

- In the congruent condition, errors are clearly faster.
- In the incongruent condition, the fast-error trend is weak.
- The model has the right qualitative direction, but not the full strength seen in human data.

## Main limitation

The model is currently better described as a mechanism test than a final fit. It needs better evidence uncertainty, better condition coupling, and a better-calibrated RT scale.

This public update should be read as an intermediate result about mechanism, not as a claim that the model already matches the full human RT distribution.

## Next step

- tighten the evidence-level uncertainty
- check the conflict-input sign and mapping
- compare full RT distributions, not only means
- compare correct vs error tails more carefully
- revisit non-decision time and RT scaling
