# R5 / Wong-Wang 导师讨论系统汇报

## 一句话结论

检查首先发现，保留版 R5 的 RT 在首次持续越界时确定，但 choice 会继续查看整段轨迹；修正这一点后，又发现晚期 target 证据到达得太晚。把真实 VGG 的层级证据压缩到更早的时间窗后，choice 与 RT 可以在同一时点确定，并在当前代表性样本上同时接近总体正确率、平均 RT 和不一致 CAF。

这说明现有 VGG 证据在计算上足以支持“早期 flanker 捕获、随后 target 恢复”，但还不能证明人类采用同一机制，也不能视为已经完成的年龄模型。

## 一、发现了什么，以及怎样处理

| 问题 | 证据 | 处理 | 当前状态 |
|---|---|---|---|
| CAF/CRF 横轴不直观 | 分位编号掩盖人类和模型实际 RT 窗口不同 | 用各箱实际 RT 中位数，并从原始试次核对 | 已解决作图与汇总问题 |
| 未越界通道可能显示为第 0 步 | 全 `False` 的首次越界布尔序列执行 `argmax` 会返回 0 | 每个通道单独记录 crossing；未越界只保存截止哨兵 | 已修正，哨兵不作为观察 RT |
| 固定时刻状态与 RT 被混为一谈 | `S(t)` 是固定时刻状态，RT 是首次通过时间 | 分开检查状态分布和首次越界分布 | 概念与分析已分离 |
| choice 与 RT 不在同一时点 | 两种 choice 规则在 2,653/10,000 个试次上不同，全部是不一致试次 | 新拟合默认在 sustained-crossing 时点确定 winner | 理论读出已对齐 |
| 修正读出后不一致正确率过低 | 旧参数下 target 多在 RT 之后才恢复 | 压缩真实 VGG 层级证据的时间安排，并重新拟合非决策时间 | 当前样本上明显改善 |
| RT 形状仍不完整 | KDE 尾部太短，条件内偏度接近 0 | 用 KDE、偏度和 delta 曲线单独揭示，不以均值/CAF 代替 | 尚未解决 |

## 二、未越界与 choice/RT 的准确含义

如果某个通道从未达到阈值，它现在保存的是模拟截止位置，同时 `crossed=False`。该位置只是删失哨兵，不是该通道的 RT。整条试次只有在确实发生持续越界时才有观察到的决策时间；当前选择时程结果中 10,000 个试次全部越界，因此图中没有把截止哨兵混入 RT。

保留版 R5 的主要问题并不是未越界，而是 RT 与 choice 使用了不同的信息窗口。旧规则可以在较早时点记录 RT，又利用之后出现的更高 target 状态改变 choice。规则对照中有 26.5% 的试次因此改变 choice，且全部发生在不一致试次。这部分准确率不能解释为标准的不可逆首次通过决策。

## 三、真实 VGG 证据是否自然包含冲突恢复

4,989 个不一致试次均表现出较早层 flanker 占优、最终层 target 占优；映射为时间输入后，这一反转也全部保留。因此这里的“自然出现”是指：没有额外加入手工冲突控制模块，VGG 层级表征本身已经产生所需的时间顺序。

这不是完整行为机制的自然出现。Wong-Wang 是否能在读出前保留这次反转、何时越界以及哪个通道获胜，仍由时间安排、循环动力学和读出共同决定。

## 四、修正读出后的两步结果

第一步只把 choice 改为 RT 时点的 winner。跨越率保持在 95% 以上时，年轻组模型正确率只有 0.633，老年组只有 0.687，说明不能把为旧规则选择的参数直接沿用到理论一致的新规则。

第二步保持真实 VGG logits 和保留版 Wong-Wang 参数不变，只搜索层级证据进入积累器的时间压缩、晚期平移和宽度，并为每个候选重新拟合非决策时间。选择结果如下：

| 组别 | 被试 / trial | Human / model accuracy | Human / model incongruent accuracy | Human / model mean RT | Crossing | CAF RMSE |
|---|---:|---:|---:|---:|---:|---:|
| 20–29 | 12 / 5,000 | 0.949 / 0.961 | 0.917 / 0.922 | 0.603 / 0.592 s | 1.000 | 0.028 |
| 80–89 | 4 / 5,000 | 0.976 / 0.979 | 0.961 / 0.959 | 0.941 / 0.891 s | 1.000 | 0.009 |

年轻组中，target 状态在读出前恢复的比例是：全部不一致试次 86.0%，正确试次 93.4%，错误试次 0%。老年组对应为 95.8%、99.9% 和 0%。因此在当前模型内，恢复是否赶在读出前出现，与 choice 形成了清楚的对应关系。

## 五、改善后仍然暴露的问题

### RT 分布

模型合并条件后的 RT 是轻度右偏：年轻组偏度 0.283，老年组 0.163；人类分别为 4.162 和 6.855。模型在一致和不一致条件内几乎对称，整体轻度右偏主要来自两类条件位置不同的混合。KDE 显示模型的慢反应尾部明显不足。

### Delta 曲线

正确试次中，人类不一致减一致的 RT 差值随时间箱增加：年轻组约 33–83 ms，老年组约 54–131 ms。模型也呈正差值，但年轻组约 188–279 ms，老年组约 299–353 ms。因此模型虽然能拟合不一致 CAF，却严重夸大了 congruency RT cost。

### 样本与拟合范围

- 仅有 12 名年轻被试和 4 名老年被试，且各被试贡献的 trial 数不相等；
- 每组 171 个候选在同一批代表性 trial 上选择和评价，没有留出被试或刺激；
- 模型没有产生一致试次错误；
- 年龄组使用不同的最优时程，可能包含过拟合，不能直接解释成稳定的年龄机制。

## 六、导师讨论时建议怎样表述

可以说：

> 我们先修正了未越界记录和 CAF/CRF 横轴，并发现原 R5 的 choice 会使用 RT 之后的信息。将 choice 与 RT 绑定后，模型暴露出晚期 target evidence 到达过晚的问题。保持真实 VGG 表征和 Wong-Wang 参数不变、只压缩证据时程后，当前代表性样本上的 crossing、accuracy、mean RT 和 incongruent CAF 都明显改善。这说明 VGG 中自然存在的 target recovery 在计算上足以支持一致的首次通过读出。

同时必须补充：

> 该结果仍是同一样本上的探索性优化。模型 RT 尾部太短、congruency RT cost 太大、没有 congruent errors，而且老年组只有 4 名被试。下一步需要冻结流程后做留出验证，而不是继续用同一批 trial 调时程。

## 七、下一步最小而关键的检验

1. 按被试或刺激划分训练与测试，冻结 choice-coupled 读出和时程搜索流程；
2. 使用被试平衡或分层目标，避免 trial 多的被试主导结果；
3. 在留出数据上同时报告 crossing、四方向 choice、CAF、KDE/尾部、delta 曲线和错误 RT；
4. 只有上述结构能泛化时，再比较共享年龄时程与年龄特异时程，并讨论年龄机制。
