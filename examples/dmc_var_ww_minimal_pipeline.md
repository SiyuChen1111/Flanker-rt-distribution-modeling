# DMC + Variational Evidence + Wong-Wang Minimal Pipeline

Run from the project root:

```bash
python examples/build_dmc_var_ww_minimal_pipeline.py
```

Then open:

- `examples/dmc_var_ww_minimal_pipeline.ipynb`

The notebook writes outputs to:

- `examples/outputs/dmc_var_ww_minimal/`

Main files:

- `example_predictions.csv`
- `example_metrics.json`
- `example_rt_breakdown.png`
- `example_dmc_traces.png`
