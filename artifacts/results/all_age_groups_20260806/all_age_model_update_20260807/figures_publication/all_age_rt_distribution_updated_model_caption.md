# Figure | Reaction-time distributions by age group

Kernel density estimates compare human reaction times (solid) with model predictions (dashed) for congruent (blue) and incongruent (orange) trials. Every panel uses the same axes and an age-specific bandwidth shared across all four curves. Densities use every finite reaction time; the visible range is 0.1-2.0 s and contains at least 99.0% of every series. The single no-crossing model trial has no reaction time and is excluded.
