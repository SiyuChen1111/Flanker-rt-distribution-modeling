# 全年龄段时间尺度修正摘要

共享决策时间尺度选择为 `0.27`。VGG 证据、模型选择、正式读取时刻和到达阈值状态均未改变；本次只重新映射模型内部决策时间，并按年龄段重估非决策时间。

一致/不一致条件的平均绝对反应时误差由 95.6 毫秒降至 3.2 毫秒。

该修正明显改善了反应时条件结构，但参数仍在同一批代表性试次上选择，尚未经过独立被试或刺激验证。因此它是更合理的诊断性时间映射，不应表述为最终确认的年龄机制。
