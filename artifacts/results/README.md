# Results Directory Guide

This directory contains generated result bundles, exploratory diagnostics, historical memos, and current supervisor-facing outputs.

Start here:

1. `ARTIFACT_DOCS_INDEX.md` for the classified Markdown documentation index.
2. `artifact_docs_inventory.csv` for the complete machine-readable Markdown inventory.
3. `r5_supervisor_followup/` for the latest supervisor-facing R5 diagnostic.
4. `natural_layer_to_time_var_ww/representative_extreme_age_subset_5000/best_model_R5_combined_best/` for the retained current R5 package.

Older experiment folders are retained for provenance. Do not treat them as current evidence unless they are linked from the top-level README, the R5 package README, or the artifact documentation index.
